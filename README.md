# BONUS UP — стартовая версия

Это безопасный каркас Telegram-бота для каталога офферов. Реальные партнёрские ссылки пока не добавлены.

## Запуск

1. Установить Python 3.11+.
2. Создать виртуальное окружение:
   `python -m venv .venv`
3. Активировать его.
4. Установить зависимости:
   `pip install -r requirements.txt`
5. Скопировать `.env.example` в `.env`.
6. В `.env` указать токен BotFather. Никому его не отправлять.
7. Указать свой Telegram user ID в `ADMIN_IDS`.
8. Запустить:
   `python bot.py`

## Что уже есть

- /start
- кнопки БУКМЕКЕРЫ и КАЗИНО
- карточки офферов
- отдельная статистика кликов
- сохранение источника `/start`
- SQLite база
- ссылки хранятся в базе, а не в коде

## Что сделаем следующим этапом

- полноценную админку внутри Telegram;
- добавление/редактирование офферов без изменения кода;
- замену реферальных ссылок;
- порядок TOP;
- GEO;
- отдельные tracking-ссылки;
- статистику по источникам рекламы;
- postback/API, когда партнёрки предоставят их;
- нормальный production-деплой на VPS.
