# Shared AI design and frontend skills

Use the three project skills in `.agents/skills/` as the default design and frontend quality toolkit:

- `impeccable`: UX critique, accessibility, responsive behavior, typography, layout, design-system quality and interface polish.
- `design-taste-frontend`: visual direction, distinctive composition, real-world product presentation and coherent page design.
- `emil-design-eng`: interaction details, component polish and purposeful animation.

Apply the relevant skill automatically to every design, frontend, UI, UX and animation task. Combine their guidance rather than treating them as separate one-off tools.

Project-specific requirements and the user's explicit instructions always take priority. Preserve each project's existing brand, architecture, content and working behavior. Do not change unrelated pages or assets. Make targeted changes and verify the result at desktop and mobile sizes before reporting completion.
